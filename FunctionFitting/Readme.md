## Function approximation Scripts

- **SupervisedLearning_v2.py**  
  Performs standard function approximation using gradient-based optimization.  

  At each training epoch, a one-shot LSR solution is computed at the current trained network state for evaluation.

- **SupervisedLearning_v3.py**  
  Solves the linearized residual system associated with LSR using optimization-based methods.

- **SupervisedLearning_v4.py**  
  Solves the same linearized residual system using iterative numerical linear solvers.
